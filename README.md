# Drf-project.

## Описание:

Проект Drf-project создан для отработки материалов по модулю DRF онлайн школы SkyPro.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/Mery-debug/DRF.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```

## Использование:

1. Откройте проект в среде программирования PyCharm или в VsCode.
2. Запустите python manage.py runserver и в postman можно посмотреть его работоспособность.

## Безопасность:

Все личные данные скрыты в файле .env, который скрыт от автокоммитов в репозиторий файлом 
.gitignore. Однако для удобства работы пример его заполнения есть в репозитории (.env.sample).
Все установленные зависимости есть в файле rerquirements.txt.

## Реализация и функционал:

Проект создан для проработки материала из домашних заданий по модулю DRF онлайн школы skypro. В этом проекте есть 
эндпоинты, реализованные через viewset и через APIView, так же настроены валидаторы, созданы отложенные задачи, есть 
сериализаторы, частично проект покрыт тестами и настроены пагинаторы в соответствии с заданием.
Этот проект создан для реализации через изученные инструменты сервиса создания, подписки и добавления на обучающие курсы 
авторизированными пользователями. Настроены ограничения на добавление курсов и уроков для неавторизованных пользователей, 
а так же на изменения "не своих" курсов и уроков. Так же настроено ограничение для пользователей, которые не заходили 
в сервис дольше месяца, их статус становится не активным. Работоспособность проекта проверена, частично тестами и 
полностью с помощью postman.
